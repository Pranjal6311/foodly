Problem Analysis
Critical Deficiencies in Commercial Aggregators
1. Monopolistic 25%–40% Markups
Commercial platforms impose high commissions on local food vendors, which are passed directly to students via inflated item rates, mandatory packaging fees, and surge surcharges.
2. Gate Congestion & Redundancy
Couriers make individual trips to identical student hostels (Boys Hostel Block A/B, Girls Hostel D), causing severe security gate friction, dropped calls, and repeated delivery charges.
3. Massive Framework Bloat
Modern delivery apps transfer 12–15 MB of JavaScript libraries, exhausting mobile batteries and causing high bounce rates on congested campus Wi-Fi networks.
4. Inefficient HTTP Polling
Repetitive 3–5 second client polling drains device battery and congests cellular networks without offering smooth real-time telemetry coordinates.

Core Innovations
Key Engineering Differentiators
🛵 Campus Batch Pooling
Aggregates student orders destined for GL Bajaj Hostels and Gate 2 into 15–20 minute arrival windows. Eliminates individual shipping charges, saving students ₹40–₹50 per meal.
⚖️ FairPrice Audit Engine
Provides direct dine-in versus online menu price transparency, empowering students with verified dish costs and exposing hidden commissions.
🥗 Macro Nutritional Calculator
Automatically evaluates calorie count, protein (g), carbohydrates, fats, and health grades (A/B/C) to promote healthy eating habits during exams and intense study periods.
📡 Server-Sent Events (SSE) Pipe
Streams continuous driver GPS coordinates directly over persistent HTTP connections without duplex WebSocket handshakes or battery-draining polling.

Mathematical Modeling
Haversine Spatial Engine & Dynamic Pricing
1. Spherical Haversine Equation
Computes great-circle displacement between restaurant $(\phi_1, \lambda_1)$ and campus drop landmark $(\phi_2, \lambda_2)$:
a = sin²(Δφ/2) + cos(φ₁)⋅cos(φ₂)⋅sin²(Δλ/2) c = 2 ⋅ atan2( √a, √(1-a) ) Distance (d) = R ⋅ c [R = 6,371 km]
Eliminates paid third-party geolocation API dependencies.
2. Dynamic Delivery Fee & ETA Matrix
// Transit ETA Calculation ETA = T_prep (15m) + (Distance / 24 km/h) * 60 // Dynamic Distance Fee Fee = Base_Fee (₹20) + max(0, (d - 1.5) * ₹12) // Campus Batch Pool Exemption if (isCampusDropZone(address)) { Fee = ₹0; // 100% Free Campus Delivery }
Ensures deterministic, student-friendly fee structures.

Limitations & Future Scope
Roadmap for Future Evolution
⚠️ Current Limitations
• Static Road Geodesics: Haversine calculations do not account for live traffic snarls in Greater Noida.

• Single-Node DB: In-memory JSON is optimal up to ~5,000 concurrent students before requiring PostgreSQL/Redis clustering.

• Interpolated Tracking: Courier GPS movement is currently simulated via linear coordinate interpolation.
🚀 Future Roadmap
• UPI 2.0 Smart Escrow: Automatic payment lock released only upon student OTP/QR verification at drop points.

• IoT Smart Lockers: Solar-powered, heated delivery lockers installed at GL Bajaj Gate 2 for contact-free pickup.

• Multi-Campus Federation: Connecting GL Bajaj, Galgotias, and Sharda universities into a shared logistics grid.
